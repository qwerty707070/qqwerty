# RoseWorld — аватарки Minecraft-сервера

Набор из 7 профессиональных 3D-аватарок в стиле Minecraft для сервера **RoseWorld**.
Все изображения 1024×1024 (1:1), готовы к использованию как аватар сервера/сообщества.

| # | Файл | Стиль | Описание |
|---|------|-------|----------|
| 1 | `01-roseworld-rose.png` | 🌹 Rose | Розово-алые объёмные буквы, огромная роза, лепестки, розовые молнии, тёмно-бордовый фон |
| 2 | `02-roseworld-fire.png` | 🔥 Fire | Раскалённые каменные буквы с лавой, скрещённые незеритовые мечи, огонь, красные молнии |
| 3 | `03-roseworld-ice.png` | 💎 Ice | Ледяные буквы с голубым неоном, роза во льду, алмазные кристаллы, снег и морозный туман |
| 4 | `04-roseworld-royal.png` | 👑 Royal | Золотые буквы, корона с самоцветами и розой, золотые искры, чёрно-золотая гамма |
| 5 | `05-roseworld-toxic.png` | 💚 Toxic | Неоново-зелёные буквы, крипер, зелёные молнии, токсичный дым и слизь |

| 7 | `07-roseworld-pvp.png` | ⚔️ PvP | Металлические буквы, скрещённые незеритовые мечи, красные молнии, осколки блоков |

## Дополнительно

- `512/` — уменьшенные версии 512×512 (аватарки для Discord/форумов, лёгкий вес).
- `preview.png` — общий превью-лист всех вариантов.

## Как использовать

- Telegram / Discord / VK: загружайте сразу `512/…` версии.
- Обложка канала / шапка: используйте оригиналы 1024×1024.
- Для круглого аватара надпись расположена по центру — при кропе в круг остаётся читаемой.
